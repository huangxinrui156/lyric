# Lyric 0.4 视觉方案（美术）

> 核对 0.3.4：`ReaderTheme` 共 6 套预设（日间 PAPER / 纸张 BEIGE / 青苔 MOSS / 夜间 NIGHT / 深绿 GREEN / 纯黑 BLACK）+ 自定 CUSTOM；设置面板只露出前四套。需求文档 MVP 写“4 套：纸白/米黄/墨绿/纯黑”，与代码命名不一致——本方案以面板四套为主，深绿/纯黑附参数。默认排版代码已是 17sp / 0.3em / 20dp。
> 视觉稿：`design/v0.4/*.png`，源码 `design/v0.4/src/`。

## 1 漫画阅读页界面层（comic-directions.png ①）
- **黑底沉浸**：画布 `#111111`（不用纯黑，和纸色漫画页有柔和边界）；纸色界面会与漫画白边抢视觉。
- 界面层默认隐藏，点中区 1/3 唤出；顶/底栏底色 `#111111` @88%（`0xE0111111`），淡入 200ms / 淡出 160ms，FastOutSlowIn；3 秒无操作不自动收起（阅读者主导）。
- 顶栏 56dp + 状态栏：返回、书名 15sp `#D0CABE`、话名 11sp `#8E897F`，右侧当前方向图标 24dp。
- 底栏 120dp：页码 `12 / 186` 12sp 等宽数字 `#D0CABE` 居中；两端总页/1 页 11sp `#8E897F`；进度轨 2dp `#3A3A3E`，已读 `#E08A6E`，拇指 12dp 圆 `#E08A6E`（拖动时放大到 16dp，上方浮出 12sp 页码气泡）。**右→左时进度条镜像**（起点在右）。下排：章节 / 方向 / 亮度 / 设置，图标 24dp、触区 48dp。
- 隐藏态可选“角落页码”（默认关）：10sp `#8E897F` @60%，右下 12dp。

## 2 阅读方向图标与首次提示（comic-directions.png ②③）
- 图标 24dp 栅格、1.6dp 线、圆端：右→左＝两页框 + 底部左向箭头；左→右＝两页框 + 右向箭头；条漫＝上下两格 + 右侧下向箭头。默认态 `#D0CABE`，当前/提示中强调 `#E08A6E`。
- 首次提示：每本书每种方向首次进入时出现一次；底部居中药丸 32dp 高、圆角 16dp、`#111111`@88%、12sp `#D0CABE`，距底 56dp，文案：“从右往左读 · 点左侧翻下一页”/“左→右：点右侧翻下一页”/“条漫 · 向上滑动连续阅读”。
- 同时“下一页”点击区亮起白色 8% 蒙层 1.2s（条漫不显示），药丸 2.4s 后 300ms 淡出；任何触摸立即消失。不弹对话框、不加遮罩。

## 3 书架混排（shelf-mixed.png）
- 统一 3 列，格子 3:4（360dp 宽屏下约 97×130dp），列距 14dp、行距 18dp、边距 20dp，行高恒定不跳。
- 文字书封面 2:3 以 `ContentScale.Crop` 顶部对齐裁入 3:4（损失约 11%，书名区通常在上）；漫画封面 3:4 Crop 居中。圆角 6dp，阴影 0/3/8 黑 18%。
- 类型角标：右上 6dp，朱红 `#B5563A` 底、`#F4EFE6` 9sp 字，“漫”/“条”，圆角 3dp；文字书无角标。漫画副标题显示“12 / 186 页”。
- 无封面占位：底 `#EAE3D6`，1dp 外框 `#E2DACB`，内缩 6dp 再一道 1dp `#D2C9B8` 细框（像书帙），竖排书名 13sp 思源宋体 SemiBold `#5A544B`，无阴影。0.3 已有的六色色块仍用于有标题无图的文字书生成封面。

## 4「全部 / 文字 / 漫画」切换
- 纯文字 + **朱红印点**：14sp，未选 `#8C8478`，选中 `#2B2A27` SemiBold，下方 9dp 处 5dp 圆点 `#B5563A`；项距 24dp；数字角标 10sp `#B0A898`（“全部”不显示）。
- 切换：圆点水平滑动 220ms spring(0.9)，文字颜色 150ms 交叉；网格内容淡入 180ms，不做横向滑页。触区 48dp。

## 5 漫画大图状态（comic-states.png）
- **加载**：先用文件头读出宽高占位，避免跳动；加载 >300ms 才显示骨架：底 `#1A1A1D`，块面 白 6%，呼吸 6%↔9% 1600ms 循环（无流光、无转圈）；>1s 在图片底边显示 2dp `#E08A6E`@70% 进度线。
- **缩放**：双击 1×→2×（再双击回 1×），250ms；双指 1–4×，到边界 0.3 阻尼回弹。缩放时先放大低清采样图，分块高清 150ms 淡入替换；>1× 时右下出现 56×76dp 小地图（`#111111`@70%，可视框 1.5dp `#E08A6E`），停止操作 1.2s 后淡出；右上倍率药丸 11sp。
- **错误**：在占位区（宽 = 屏宽-40dp，条漫高 = 宽×1.4）画 1dp 虚线框 `#45444A`、圆角 6dp、底 `#1A1A1D`；36dp 破图线稿 `#8E897F`；标题“这一页没能打开”15sp 宋体 `#D0CABE`；原因 12sp `#8E897F`（文件名 · 原因）；按钮“重试”(朱红描边 `#E08A6E`) /“跳过此页”(描边 `#45444A`)，32dp 高、圆角 16dp。翻页手势不被拦截。
