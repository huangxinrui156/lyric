# Lyric 0.3 「阅读体验优化」需求与验收标准

0.2 已完成「我的」页 P0+P1。0.3 不加新页面，只把"读"这件事做稳、做顺：先守住数据，再守住手感。

| 项 | 优先级 | 用户故事 | 验收标准 |
|---|---|---|---|
| 进度与时长不丢 | P0 | 手机在后台杀掉 App 后，我回来时位置和今天读的时长都还在。 | 进度在翻页后 ≤1 秒落盘；SessionTracker 每 15 秒写一次进行中会话（endAt 滚动更新），onPause/onStop 立即补写；`adb shell am kill` 与强杀各测 20 次，进度偏差 0 页、时长损失 ≤15 秒。 |
| 真机性能基准 | P0 | 我在自己的手机和便宜的手机上都能顺滑地读。 | 基准机 OPPO Find X9 Pro，下限机定一款 4GB 内存入门机（如 Redmi A 系列）；Macrobenchmark 测：翻页帧耗时 P95 ≤16.7ms（下限机 ≤25ms）、10MB TXT 冷打开 <1.5s（下限机 <3s）、搜索首条 <1s；结果写入 README，CI 外每版手动跑一次。 |
| 预分页与骨架屏 | P0 | 打开大书时我立刻看到正文，而不是转圈。 | 先排当前章与前后各 1 章，其余后台分页；首屏 <500ms 显示正文或纸色骨架行（无旋转图标）；改字号后重新分页期间位置不跳。 |
| 阅读页信息栏 | P1 | 我想安静地知道时间、电量和读到哪了。 | 顶部章节名、底部页码/百分比/时间/电量，字号为正文 70%、低对比色；每项可单独关闭；默认只显示章节名与百分比。 |
| 长按选词复制 | P1 | 我想把喜欢的一句话复制或存成摘录。 | 长按选中词语，拖动手柄扩选，跨页可选；菜单仅 复制 / 存为书签摘录 / 分享 三项；选区在翻页模式与滚动模式都可用。 |
| 音量键翻页 | P1 | 单手在通勤时翻页。 | 设置中开关，默认关；音量下=下一页，可互换；仅阅读页生效，菜单打开时恢复系统音量。 |
| EPUB 排版子集 | P1 | 带图和日文注音的书也能正常显示。 | 支持 CSS 子集：对齐、缩进、粗斜体、标题字号、居中、分隔线；内嵌图片按宽度适配并可点开大图；ruby 注音显示在字上方；内嵌字体在"采用书籍样式"时生效；20 本样本书无崩溃、无空白页。 |

## 暂不做
| 项 | 理由 |
|---|---|
| 仿真翻页 | 实现与调优成本高，与克制定位不符；放 V1 后期。 |
| 亮度手势 | 与翻页、选词手势冲突。 |
| 自动滚动 | 使用频率低，等 TTS 一起做。 |
| 平板/折叠屏双页 | 缺测试设备；0.3 只保证横屏单栏可读不崩。 |
| EPUB 完整 CSS（浮动、表格、多栏） | 投入产出低。 |
