# Lyric v0.3.1 变更记录

基线：`66012f2`（v0.3）。发布版本：`versionName = 0.3.1`，`versionCode = 4`。

## 1. EPUB 导入：复现、根因与修复

本次新增的是真正的 EPUB ZIP 文件，位于 `app/src/test/resources/epub/`，不是文件后缀伪装或只测试 XML 字符串。每本均将内容为 `application/epub+zip` 的 `mimetype` 作为首个、不压缩的 ZIP 条目，并包含 container、OPF、spine、XHTML 和导航。内容为项目原创测试文字，无第三方版权依赖。`python3 scripts/create-epub-fixtures.py` 可确定性地重新生成。

| 文件 | 覆盖内容 |
| --- | --- |
| `epub3-basic.epub` | 常规 ASCII 路径，EPUB3 nav.xhtml，隔离基本解析行为 |
| `epub2-root.epub` | 根目录 book.opf，Navigation/toc.ncx |
| `epub2-nested.epub` | OEBPS/content.opf，NCX 的 ../ 相对链接 |
| `epub3-nested.epub` | EPUB/package/book.opf，独立 Navigation/nav.xhtml |
| `epub3-literal-percent.epub` | Books/100% + rain/package.opf，container 的编码路径 |

后四本都包含中文、空格、加号和百分号的 ZIP 文件名；manifest 中使用 URL 编码的 href，包含 ./、../ 路径，导航片段使用编码的中文和加号。断言章节按 spine 排序、目录名称、章节定位及片段对应正文，而非仅断言“没有抛异常”。

### 已复现的根因

1. **导入器在读取源文件前仅按 DISPLAY_NAME 的后缀选择解析器。** `LibraryRepository.importOne()` 的第一句就调用 `registry.parser(...)`；SAF 文档 ID 是不透明的，DISPLAY_NAME 可能没有扩展名或查询不到。此时不管 MIME 是 EPUB 还是通用二进制，也不管内容是否是 EPUB，都会先被“暂不支持”拦截。旧的缺省名 `未命名.txt` 还可能把 ZIP 当成 TXT。原有解析单测直接调用 `EpubParser`，没有覆盖这一导入入口。
2. **ZIP 条目名与 URI href 共用 URLDecoder，混淆了两种不同的命名规则。** ZIP 文件名是字面值；例如 `雨 + 100%.xhtml` 中的 `%` 不是 URI 转义。修复前新增 fixture 测试实际失败：`IllegalArgumentException: URLDecoder: Illegal hex characters in escape (%) pattern`。对已经解析出的父目录再次解码，也会破坏含 `%` 或字面 `%20` 的路径。原代码另将 container 的 full-path 直接作为 ZIP key，没有统一按引用规则解析。
3. **导航 fragment 未解码。** `%E9%9B%A8%2B%E5%8F%B6` 无法命中 XHTML 中的 `id="雨+叶"`，原代码静默退到章首，目录位置错误。

修复后先通过 ContentResolver 把输入流复制到有 200 MB 上限的临时文件，再按 ZIP 魔数、显示名/URI 后缀及 MIME 选择解析器。EPUB 仍必须通过 container、OPF 和 spine 校验，任意 ZIP 不会自动成为可读书籍。数据库保存实际识别的 extension，后续缓存重建、授权检查和重新打开仍使用原 content:// URI。去重重新授权保留既有阅读进度。导入结束保留最近一次错误的文件名和原因，避免仅显示“失败 1 本”。

所有文件选择入口统一接受 `application/epub+zip`、`application/octet-stream` 和 `text/plain`；目录扫描也接受支持的 MIME。`EpubPaths` 分开处理字面 ZIP 名与 URI 引用，仅解码引用一次，保留加号，解析相对路径和 fragment，并保留根目录逃逸检查。

`EpubSafImportTest` 在 Robolectric 下注册 ContentProvider，实际经过 `query(DISPLAY_NAME)`、`getType()`、`openInputStream(content://...)`、临时文件、解析、Room、缓存重载及进度保存。五本 fixture × 两种 MIME 加空 MIME × 有扩展名、无扩展名、空 DISPLAY_NAME，共 45 种组合全部检查；另有魔数覆盖错误显示后缀、URI 后缀回退和路径安全测试。

新增 Android 仪器测试 `EpubDocumentsProvider` 和 `RepositoryTest.epubFixturesThroughRealSafProviderBothMimeTypesAndMissingExtensions`，使用真正的 DocumentsProvider 文档 URI（五本 × 两种 MIME × 两种显示名，共 20 种组合），供设备复验。`EpubDeviceTest` 另测常规 EPUB 的 Android 运行时解析。

**验证边界：** 本次没有连接物理 Android 设备；尝试启动本机 API35 模拟器，但模拟器停在启动阶段，未达到 ADB ready。因此不声称已在故障手机上复现/通过，也不将上述已证实的失败条件推断为“所有正常命名的 EPUB 必然失败”。如果特定手机的普通 ASCII 路径 EPUB 仍失败，应使用本次保留的错误消息和仪器测试继续定位，不能把 JVM 结果当作真机证据。

## 2. 横屏正文与目录/书签面板

阅读器、目录及书签抽屉共用 `systemBarsIgnoringVisibility ∪ displayCutout` 的安全内容区域，横竖屏均生效。沉浸式系统栏隐藏/显示不会让正文突然扩宽到刘海、手势区或侧边导航栏下方。原先硬编码的上/下留白改为安全区内的较小留白；真实正文尺寸变化时重新分页，保留规范字符锚点。

抽屉宽度上限 360 dp，标题最多两行；作为有遮罩的模态抽屉显示，打开及打开过程中禁用正文触摸翻页，音量键交还系统。菜单底部内容限制高度并可滚动，避免短横屏溢出。大图对话框也尊重安全区。

## 3. 阅读设置：离散亮度/字号及颜色

亮度改为 −/+ 控件：1% 最低档及 10%、20%……100%。字号为 12–36 sp、每次 1 sp 的 −/+ 控件，显示具体数值，边界按钮禁用，附带无障碍标签。已保存的任意小数值在用户操作前保持原值，操作后进入相邻档位。

字号不再有自由滑动或淡紫色轨道。其余高级设置滑条显式使用应用 primary 与 outlineVariant，避免 Material 默认轨道颜色不协调。

## 4. 仅调整未设置字段的默认值

字号 18 → 17 sp，段距 0.6 → 0.3 em，页边距 28 → 20 dp；默认行距保持 1.9。继续按全局 → 内容类型 → 本书合并设置，不重写已保存的显式字号、段距、边距。新增 DataStore 测试验证新默认值及旧设置恢复后仍保留 18/28/0.6。

## 5. 底部阅读百分比

Canvas 每次分页定位和滚动更新都发布实际可见页/行的规范字符位置，底栏直接观察这一位置；翻页在同一个输入事件内更新 Canvas、引擎及进度写入，不再依赖下一轮 Compose rebind 才能前进。滚动拖动和惯性滚动经过相同通知路径，目录/书签/进度跳转及重新分页也刷新可见位置。

另修复大书开头的舍入问题：非零但小于 0.1% 时增加必要的小数位，避免已翻页仍被一位小数显示为 0.0%；正常进度维持一位小数。新增测试验证五种翻页模式、连续前进/后退、滚动拖动和横屏尺寸重排，以及大书早期百分比的显示。

## 6. “我的”设置行更紧凑

保持字体、箭头、副标题、分隔线的样式；行标题 18 → 16 sp，上下 padding 8 → 6 dp，副标题间距 8 → 6 dp，分隔线前间距 20 → 14 dp。

## 7. 仿真翻页

`PageMode.CURL`（“仿真翻页”）与覆盖、平移、滚动、无动画并列，沿用按作用域保存的设置。Canvas 截取旧页，实际下一/上一页由原阅读器排版；Compose Canvas 绘制曲线裁剪、纸张背面、淡反射文字、渐变及投影，420 ms 动画同时支持前后翻页，跨章/跨分页窗口等待目标正文就绪再开始。旋转或排版改变取消旧尺寸动画，动画期间防止重复翻页。

原阅读锚点与 Room 数据结构不变。新增真实图形渲染测试，验证前后两个方向的起点、终点、中间帧、目标页露出与折面阴影，而非仅增加枚举项。

## 8. 音量键默认启用

新默认值为开启，下键下一页、上键上一页，仍可互换。目录、书签、菜单、搜索、设置、大图及选区菜单打开时交还系统音量；离开阅读页释放路由。已显式关闭的设置保留，测试验证开启默认值与旧关闭值恢复。
