# v0.9.3 跨 OEM 兼容性审计

## 范围 / 方法

- 基线：`feature/0.9`，`c333b45`（0.9.3 leaf adaptive icon / phone 双页 subtitle），2026-10-31。原审计以此为基线。本轮（2026-11-01）按 owner 批准修复 R1–R6；不提交，不改名称、图标、版本、布局或正常情况下的动画参数。
- 阅读导入、解析、位图、Room/DataStore、生命周期、Insets、Compose/Canvas 动画代码，结合现有测试及 Android / Coil 2.7.0 官方资料。原审计新增混合 ZIP 分隔符回归。本轮补充 R1–R6 专项测试；没有升级依赖，解析 JSON 格式和进度版本保持兼容。
- 下文“五系”指 OPPO ColorOS、Xiaomi HyperOS、vivo OriginOS、Honor MagicOS、Samsung One UI。表示共同代码路径的适用范围，**不表示已在这些 ROM 上复现**。API 26/27 的旧设备问题不等同于当前 HyperOS / OriginOS / MagicOS 问题。
- 原审计 `adb devices` 无设备；本轮仍为源码修复及主机测试，不包含 OEM 真机、GPU、后台清理或折叠姿态实测。R1–R6 与本轮专项测试使用最终工作树行号；F1–F4 及原“已核对”表保留原审计行号，标为 `HEAD` 的是原修前行号。为缩短表格，`M/` = `app/src/main/java/com/lyric/`，`T/` = `app/src/test/java/com/lyric/`。
- 起始已有 `design/v0.9/export-card.png`、`design/v0.9/noise.png`、`design/v0.9/concepts/` 变更，原样保留。
