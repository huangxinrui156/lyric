# v0.9.3 跨 OEM 兼容性审计

## 范围 / 方法

- 基线：`feature/0.9`，`c333b45`（0.9.3 leaf adaptive icon / phone 双页 subtitle），2026-10-31。审计与修复基于 `c333b45`（0.9.3）。随后由执行代理将修复随 `versionCode=31` / `0.9.4` 提交上传；应用名称、图标、字幕、布局及动画参数保持不变。
- 阅读导入、解析、位图、Room/DataStore、生命周期、Insets、Compose/Canvas 动画代码，结合现有测试及 Android / Coil 2.7.0 官方资料。新增一个混合 ZIP 分隔符回归用例。没有升级依赖或重构存储、渲染架构。
- 下文“五系”指 OPPO ColorOS、Xiaomi HyperOS、vivo OriginOS、Honor MagicOS、Samsung One UI。表示共同代码路径的适用范围，**不表示已在这些 ROM 上复现**。API 26/27 的旧设备问题不等同于当前 HyperOS / OriginOS / MagicOS 问题。
- `adb devices` 无设备；本次是源码审计及主机测试，不包含 OEM 真机、GPU、后台清理或折叠姿态实测。证据默认使用修后工作树行号；标为 `HEAD` 的是修前行号。为缩短表格，`M/` = `app/src/main/java/com/lyric/`，`T/` = `app/src/test/java/com/lyric/`。
- 起始已有 `design/v0.9/export-card.png`、`design/v0.9/noise.png`、`design/v0.9/concepts/` 变更，原样保留。

## 未修项与建议

- R1–R6保持现状，理由见表。优先测量低内存大书峰值和 pause落盘时延，再决定预算/取消策略；不增加常驻服务、自启动引导或品牌白名单。
- 旧 CBZ解析缓存没有自动迁移；新解析使用修正规则。对历史库升级应另验证章节变化与 locator映射，不能为修目录直接改既有进度。
- F1/F3/F4有明确代码/API证据，但本次没有对应 Android 8真机、SVG截图或完整漫画生命周期端到端测试。以下均为**待执行**验收，不能用主机单元测试替代。
