# Lyric 0.4.0-p0 (versionCode 8): P0 only

Based on 0.3.4 (965c92c). P1 (条漫, shelf tabs and 3:4 mixed grid, 20-EPUB audit) is waiting for review.
Theme scope: 日间 / 纸张 / 青苔 / 夜间. The 深绿 / 纯黑 / 自定 parameters are in code, but those themes are not exposed in the settings panel.

## P0 status against the 0.4 spec

| Item | Status | What can be verified off-device |
|---|---|---|
| Comic import: CBZ/ZIP/image folder | Done | `ComicParser` is registered in `ParserRegistry` with `contentType=COMIC`. Natural sort (2 before 10, digit runs compared numerically, case-insensitive). Sub-folders become chapters; a flat archive is split by a filename prefix such as `ch01_003`. Cover = first image. `__MACOSX` and hidden files are ignored. GBK/CP437 entry names are retried. ZIPs are told apart by content: container.xml/OPF/XHTML means EPUB, images mean comic. An image folder is any folder chosen with 「选择文件夹」 that contains images but no books; it is packed into a deterministic uncompressed CBZ, so a re-import counts as a duplicate. A ZIP without images reports 「压缩包里没有可识别的图片」 in the error dialog. **500 pages / 150 MB: parse 135 ms on the JVM** (target < 3 s). Only a 64 KB header is read per image. |
| Comic paged reading | Done (needs device feel/perf check) | `ComicReaderEngine` + `ComicReaderScreen`: #111111 immersive background. Right-to-left is the default, left-to-right is switchable, and the choice is saved per book (`SettingsScope.BOOK`, `comicDirection`). Tap zones: in RTL the left third is "next"; the middle shows the top/bottom bars (200/160 ms fades, #111111@88%). The progress slider is mirrored for RTL. Page count is `12 / 186` in monospace. Double tap toggles 1×↔2× (250 ms); pinch zooms 1–4×; pan while zoomed, with the pager locked while zoomed; zoom-level pill. The pager preloads 2 pages either side. Decoding happens on IO with power-of-two sampling to the screen size and a 48 MB per-bitmap cap, cached in an LRU of 1/8 of the heap. Placeholders use the header's aspect ratio. The skeleton appears after 300 ms (6%↔9% breathing) and a progress line after 1 s. Errors show a dashed frame, 「这一页没能打开」, file name · reason, and 重试 / 跳过此页. The first-time hint (once per book per direction) shows a pill for 2.4 s plus an 8% white flash on the "next" zone for 1.2 s. The direction icons are drawn per the spec grid. Locator = (chapter, 0, page); progress, bookmarks and reading time reuse the existing tables, and statistics count pages for comics. Volume keys turn pages. Covered by `ComicReaderTest` (Robolectric: taps, progress persistence, direction switch). |
| Selection and page-curl polish | Code done; **the spec's acceptance is on-device** | Long press is 400 ms (was the system default of about 500 ms). Holding a handle at the page edge turns the page after 600 ms (was 450 ms) and repeats every 600 ms. A curl never starts while a selection, long press or handle drag is active (and the curl already blocked long press). Per-theme selection fill and handle colours come from selection-palette (§6), with 12 dp teardrop handles and a 48 dp hit area. Per-theme curl paper back, show-through, a 24 dp cast shadow and a 16 dp under-page dim, plus a 1 dp fold highlight, come from curl-backs (§7). The floating selection **menu** is still the system ActionMode, so the menu colours from §6 are **not applied** (it would need a custom popup). |
| Device benchmark + kill tests | Tooling ready, **not measured** | (1) Hidden in-app 「性能自测」: 我的 › 关于, tap the version line 7 times. It runs these on the phone with no adb: 10 MB TXT cold open (parse + first screen), first screen, page-turn P95 (**CPU draw time of one page, not a GPU frame**), first search hit, and comic page decode P95. There is a low-end-device threshold toggle and a 「复制结果」 button. (2) In-app 「杀进程自检」: while it is on, each page turn is committed synchronously to SharedPreferences. On the next process start the app compares that with Room's progress and session end. Results (pass = 0 deviation, time loss ≤ 15 s) are listed and can be copied. (3) Unchanged adb tooling: `scripts/run-benchmarks.sh` (Macrobenchmark, true frame timing) and `scripts/kill-test.sh` (20 × am kill + 20 × force-stop). ## Notes
- Comics always keep a private copy (`files/sources-v1/<sha256>`) for random access. That uses storage equal to the archive size.
- No new regexes with braces were added; the single ICU-safe regex is the chapter-prefix pattern.

## 0.4.0-p0.1 (versionCode 9)
- The text reader's selection menu is now a custom `PopupWindow` instead of the system floating ActionMode, per design §6. It has exactly three actions: 复制 (clipboard), 摘录 (saved as a bookmark excerpt through the existing `onExcerpt` → `vm.bookmark`), and 分享 (Android share sheet via `ACTION_SEND` and a chooser).
  - Menu colours follow the §6 table. On 日间/纸张/青苔 the menu background equals the theme ink (#2B2A27 / #3A362F / #2F3529). On 夜间 the design specifies #2A2B2F with #D0CABE text, because the night ink is a light colour. Text is 13sp, padding 8/14dp, corner radius 10dp, 18dp between items, 14dp elevation, and it appears with a 160ms fade plus a 0.96→1 scale.
  - Selection fill is vermilion at 22% (日间), 24% (纸张), 26% (青苔, #A84E33) and 28% (夜间, #E08A6E).
  - The menu sits 8dp above the selection's first line, or below the selection when there is no room. It is clamped inside the view minus the system-bar and display-cutout insets.
  - It dismisses on: a tap outside (including on the page), PopupWindow outside-touch, any action, a page turn, and dragging a handle (it reopens on release).
- `SelectionPopupTest` (Robolectric) covers the 4 themes' colours, the three labels, copy/excerpt/share, placement inside bounds, and the outside-tap and page-turn dismissals.

## 0.4.0-p0.2 — 漫画阅读方向（修订 a）
- 不弹对话框。文件声明了方向就直接用（ComicInfo.xml `<Manga>`：YesAndRightToLeft→从右往左，No→从左往右）；没声明就默认从右往左。
- 每本书第一次打开时，底部显示 32dp 提示条（v0.4-visual.md 第 2 项），带三个可点的方向图标：从右往左（默认选中）、从左往右、条漫。2.4 秒内没碰就淡出，保持默认。
- 每本书单独记住方向（SettingsScope.BOOK），阅读器顶栏和底栏的方向按钮按 从右往左 → 从左往右 → 条漫 循环切换。
- 新增基础条漫模式：页面撑满宽度纵向连续排列，高度按图片头部尺寸预留；进度、滑块、章节跳转、音量键都能用。

## 0.4.0-p0.3
- 图片版/固定版式 EPUB（如《再见绘梨》）导入时识别为漫画，用漫画阅读器打开。判定条件：`rendition:layout` 为 pre-paginated，或 spine 中的页面基本都只有一张 `<img>` 或 `<svg><image>`（≥90%；pre-paginated 时 ≥60%）。图片按 spine 顺序直接从 EPUB 压缩包里读，章节取自 nav/NCX。`page-progression-direction` 作为文件声明的方向。
- 旧版本当成文字书导入的 EPUB，打开时会重新检测一次（contentRevision < 4）。如果是图片书，就转成漫画、生成封面，进度回到第一页。
- 漫画页面按比例缩放、上下左右都居中，背景固定为 #111111，加载中也一样。底栏居中显示 `12 / 186` 页码。
- 每本书记录方向是否手动选过（comic_hints `chosen_<id>`）。没手动选过时，文件声明的方向优先，首次打开提示（hint_v3）也会再显示一次，包括旧版本打开过的书。
- 文字阅读器：单独成行的图片铺满页面宽度，不留页边距。（p0.4 已按美术设计修改，见下）

## 0.4.0-p0.4 — 文字阅读器插图（美术设计修订 p0.3 第 5 项）
- 单独成行的图片不再铺满屏幕，宽度和正文一样，左右各 20dp（即正文页边距），和文字对齐。按比例缩放，水平居中，太高的图按页面高度缩小。
- 图片上下各留 1em（当前正文字号）的空白。
- 点击图片全屏打开，可双指缩放、拖动（沿用已有的插图查看器）。
- 页面裁剪恢复为正常页边距（p0.3 为了让图片出血放宽到了全屏宽）。现在没有内容会超出文字栏，所以恢复是安全的。
