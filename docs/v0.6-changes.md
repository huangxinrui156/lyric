# Lyric 0.6.0 变更说明

版本：`versionName = 0.6.0`，`versionCode = 17`。数据库由 v6 升级到 v7。

## 已完成：P0

- **书架 / 画架分区**：新增 `books.section`，取值为 `BOOK` / `COMIC`。两区分别统计数量、显示收藏、选择继续阅读条目；搜索、格式筛选和排序均先限定当前分区，两区的排序偏好独立持久化。点击底栏第一个 tab 只返回当前分区，不切换书架 / 画架。
- **升级与数据保留**：`MIGRATION_6_7` 只新增并回填分区，已有 `contentType = COMIC` 的条目（包括此前已识别的图片 EPUB、500 页漫画）进入画架，其余留在书架。不重建、不清空进度、书签、划线或统计表。迁移已注册，v7 Room schema 已导出。
- **自动分类与导入**：沿用已有 CBZ / ZIP、图片文件夹、固定版式及纯图片 EPUB 解析与识别。新增单张 PNG / JPEG / GIF / WebP / BMP 导入，通过文件签名识别并打包为单页漫画，复用现有漫画阅读器。支持 ZIP 文件名识别。新条目按实际内容类型进入对应分区。
- **分区记忆**：DataStore 保存最后选择的分区；首次读取设置之前显示和纸背景，避免启动时短暂显示错误分区。分区设置也纳入备份恢复，兼容没有此字段的旧备份。
- **切换入口**：标题右侧、“+”左侧新增 32dp 高的“书 ⇄ 画”胶囊，当前一侧使用现有 Moss 苔绿。
- **画架界面**：标题为“Lyric · 画架”，副标题为“本地珍藏 N 部 · 一格一格画”；底栏为“画架 / 本地导入 / 我的”；筛选为“全部 / CBZ / EPUB / 最近”，并调整空状态及导入文案。
- **漫画继续阅读**：按实际章节内图片数量和 `ProgressRow.page` 计算跨章节的全书页码，显示“第 12 页 / 186”格式，不显示漫画章节。摘要读取在 IO 线程执行，不触发阅读器升级或改写阅读锚点。加载中及源文件无法读取时有明确提示。
- **画架导入默认筛选**：从画架进入“本地导入”或“+”导入时默认选择漫画格式，文件选择器包含 CBZ、ZIP、EPUB、图片及通用二进制 MIME。保留“所有格式”选项，以兼容错误标注 MIME 的文件提供者。文件夹选择仍使用系统目录授权；最终分类以解析结果为准。
- **切换动画**：Compose Canvas 实现 700ms 线稿过渡，和纸背景、`#2B2A27` 单色、2dp 圆头线条和轻微抖动。0–250ms 淡出旧网格并逐段画出打开的书，250–500ms 将书页路径变形为三个漫画分格并画出两笔火柴人，500–700ms 淡出线稿、新网格从底部升起；切回时反向播放。
- **减少动画与操作保护**：检测 `Settings.Global.ANIMATOR_DURATION_SCALE == 0` 时使用 200ms 交叉淡入淡出，不绘制线稿、不位移。帧时钟不受系统时长倍数影响，避免缩放为 0 时直接跳过交叉淡入淡出。切换状态同步锁定，动画期间拦截点击、返回及辅助功能操作，导入结果弹层延后显示，连续点击不会叠加动画。

## 已完成：P1

- 长按收藏显示“移到画架”或“移到书架”，同时保留移出收藏操作。移动只更新分区，不改变内容类型和阅读器，不改动进度、书签、划线；重复导入同一文件保留手动分区。
- 修正移出收藏确认文案，准确说明进度会保留。

# 0.6.1 (versionCode 18) — 切换动画换成美术设计的线稿
- 线稿改用 `design/v0.6/src/anim.html` 里的原始 SVG 路径（帧①摊开的书，帧②三格分镜、两个小人和地平线），用 `PathParser` 转成 Compose Path。240×180 画面等比缩放到屏宽 72% 以内并居中；线宽在屏幕上固定为 2dp，圆头。
- 时间轴 700ms，采用 FastOutSlowIn 缓动：
  - 0–250ms：书架网格淡出，书的两页轮廓按虚线偏移 1→0 描出；
  - 250–500ms：书淡出，三个分格描出，随后是两个小人和地平线；
  - 500–700ms：线稿淡出，画架网格从下方 12dp 升到原位。
  - 切回书架时整条时间轴反向播放。
- 线条颜色：日间 #2B2A27，夜间 #D0CABE。动画背景跟随当前主题，夜间不会闪白。
- 系统开启「减少动画」时，仍是 200ms 交叉淡入淡出。
