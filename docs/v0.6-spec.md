# Lyric 0.6 规格（功能设计 定稿）

CBZ 导入已经有了，不要重做。导入的条目自动分类：CBZ/ZIP、图片文件夹、单张图片、固定版式或纯图片 EPUB 归入 **画架**（漫画），其余归入 **书架**。

## P0
1. **分区**：书架和画架各自只列自己的书。已有的漫画（《再见绘梨》、500 页测试书，也就是已识别为图片书的条目）升级时通过 DB 迁移归入画架，进度、书签、划线都保留。App 重新打开时回到上次所在的分区（持久化保存，进程被杀后也能恢复）。
2. **切换**：标题右侧、「+」左侧放一个 32dp 高的胶囊「书 ⇄ 画」，当前一侧填苔绿（沿用现有的 Moss 色）。点底栏第一个 tab 不切换分区。
3. **画架页**：
   - 标题「Lyric · 画架」，副标题「本地珍藏 N 部 · 一格一格画」（书架保持「本地珍藏 N 本 · 一页一行诗」）。
   - 底栏「画架 / 本地导入 / 我的」。
   - 筛选标签「全部 / CBZ / EPUB / 最近」。
   - 继续阅读卡片显示「第 12 页 / 186」（页码 / 总页数），不显示章节。
   - 搜索和排序只作用于当前分区。
   - 从画架进入「本地导入」时，默认筛选漫画格式。
4. **切换动画**，总长 700ms。线稿单色 #2B2A27，线宽 2dp，带轻微抖动，全程和纸白背景：
   - 0–250ms：网格淡出，同时在屏幕中央一笔画出一本打开的书；
   - 250–500ms：书页的线条变形为三个漫画分格，外加两笔火柴人；
   - 500–700ms：线稿淡出，新网格从底部升起。
   - 切回时反向播放。
   - 系统开启「减少动画」（动画时长缩放为 0 或移除动画）时，改为 200ms 交叉淡入淡出。
   - 动画期间忽略点击，连续点击不叠加。
   - 美术设计之后可能会发逐帧图或 HTML 样例，现在先用 Compose Canvas 路径动画实现。
