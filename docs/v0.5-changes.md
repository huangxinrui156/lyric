# Lyric 0.5.0 (versionCode 13)

## P0
1. 目录：当前章左侧朱红竖线 + 圆点；每章「已读完 / 读到 N% / 未读」与 3dp 苔绿进度条（`tocProgress`）。
2. 书内搜索：原有功能，结果改为章节名小字在上、命中词朱红 26% 底色。
3. 书签：可加/改备注（✎ 苔绿），右上角切换「按时间 / 按章节」排序。
4. 划线与笔记：选区菜单改为 复制/划线/笔记/分享。新表 `highlights` 以「章节 + 章内字符偏移」锚定，改字号、重排不偏移；正文以朱红选区色绘制。目录抽屉新增「划线」页，按章节分组，左侧 2dp 朱红线，可写想法/删除。旧「摘录」（存成书签的选中文字）在打开该书时自动迁入划线（`Annotations.migrateExcerpts`）。
5. 书架：40dp 胶囊搜索框（书名/作者），排序胶囊 最近阅读/导入时间/书名（选中苔绿填充，存 `shelf_sort`，兼容旧 `sort_title`）。
6. 文件夹导入：原有 SAF 递归导入与去重；结束时只弹一个底部汇总（新增 N 本 · 跳过重复 N 本 · 来源路径），不再逐本提示。
7. TXT 编码：原有 BOM/UTF-16/严格 UTF-8 校验 + GB18030(GBK 超集) 回退，已有 EncodingTest。
