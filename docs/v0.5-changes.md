# Lyric 0.5.0 (versionCode 13)

## P0
1. 目录：当前章左侧朱红竖线 + 圆点；每章「已读完 / 读到 N% / 未读」与 3dp 苔绿进度条（`tocProgress`）。
2. 书内搜索：原有功能，结果改为章节名小字在上、命中词朱红 26% 底色。
3. 书签：可加/改备注（✎ 苔绿），右上角切换「按时间 / 按章节」排序。
4. 划线与笔记：选区菜单改为 复制/划线/笔记/分享。新表 `highlights` 以「章节 + 章内字符偏移」锚定，改字号、重排不偏移；正文以朱红选区色绘制。目录抽屉新增「划线」页，按章节分组，左侧 2dp 朱红线，可写想法/删除。旧「摘录」（存成书签的选中文字）在打开该书时自动迁入划线（`Annotations.migrateExcerpts`）。
5. 书架：40dp 胶囊搜索框（书名/作者），排序胶囊 最近阅读/导入时间/书名（选中苔绿填充，存 `shelf_sort`，兼容旧 `sort_title`）。
6. 文件夹导入：原有 SAF 递归导入与去重；结束时只弹一个底部汇总（新增 N 本 · 跳过重复 N 本 · 来源路径），不再逐本提示。
7. TXT 编码：原有 BOM/UTF-16/严格 UTF-8 校验 + GB18030(GBK 超集) 回退，已有 EncodingTest。

# 0.5.2 (versionCode 15) — 选区拖动修复
- 根因：选区菜单 PopupWindow 设为 outsideTouchable，手指按到选区手柄时先触发菜单「外部点击」关闭，回调又清掉了选区，所以手柄永远拖不动。现在菜单不再响应外部点击，点正文空白处由阅读视图自己取消选区。
- 长按先选一个词（Android ICU 词典分词；单个汉字会补成两字词），手指不抬继续拖就会以这个词为锚点逐字扩展，向前、向后都可以。
- 手柄：朱红水滴，视觉 18dp，触控 48dp，分别在首字左下角和末字右下角。拖动时显示放大镜（140×48dp，12dp 圆角，1.5 倍，在手指上方 48dp，Android 10 及以上）。
- 拖动期间隐藏菜单，松手后 150ms 淡入。菜单放在选区上方 8dp，上方放不下就放到手柄下方，不会盖住选中的文字。
- 拖到页面上下边缘（翻页模式下也包括左右边缘）会自动滚动或翻页，可以跨页、跨段落选择。
- 点「划线」立即生效。点已有划线弹出底部面板：改颜色（朱红、苔绿、赭黄、灰蓝）、写想法、删除。
- DB v5 → v6（`MIGRATION_5_6`）：highlights 新增 `color` 列，默认 0 = 朱红；章节和偏移量格式不变。
- 新测试：长按后不抬手拖动扩展选区、拖动手柄时保留选区并隐藏菜单。
