## 验证与复验

本机验证命令：

```bash
export JAVA_HOME=/home/box/jdk17 ANDROID_HOME=/home/box/Android
./gradlew assembleDebug test
./gradlew :app:assembleBenchmark :macrobenchmark:assembleBenchmark :app:assembleDebugAndroidTest lintDebug
bash -n scripts/run-benchmarks.sh scripts/kill-test.sh
```

2026-10-30 本机验证通过：`assembleDebug test`、应用benchmark APK、Macrobenchmark测试APK、debug Android集成测试APK均编译成功；`lintDebug`无错误。54项单元测试在debug/release/benchmark三种变体各执行一次，共162次，0失败、0跳过；另3项基准结果解析/门限校验主机测试通过，两个shell脚本语法检查通过。Android仪器测试和真机脚本未执行。

```bash
python3 -m unittest discover -s scripts -p 'test_*.py'
```

测试覆盖：立即且有序的进度写入；进行中会话更新/暂停/停止/午夜/墙钟变化；信息栏默认与设置序列化；音量键路由；分页任务排序；不同字号与屏幕宽度的真实分页；选词/跨章/emoji；EPUB样式/图片/ruby/字体资源；Room迁移；旧EPUB锚点与孤立书签升级；备份恢复与会话去重。

没有连接Android设备。真机帧时间、冷打开、搜索首帧、首次骨架显示、kill/force-stop各20次、长按跨页触控以及20本真实EPUB巡检均不声称通过。运行方式与回填表见README。页面卷曲、亮度手势、自动滚动、双页和完整EPUB CSS均未加入。
