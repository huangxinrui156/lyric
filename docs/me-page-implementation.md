## 数据约定

- `reading_sessions(id, bookId, startAt, endAt, durationSec, chars)`：UUID 会话片段，bookId 为导入时原文件 SHA-256，无级联。durationSec 使用单调时钟，时间戳精确到秒；跨午夜片段即使短于 10 秒仍保留，10 秒门槛对拆分前会话生效。
- `finished_books(bookId, title, finishedAt)`：独立于书架的唯一完成记录，重读不重复累计本数。v1 percent ≥99% 的书在迁移时补入；v1 没有历史时长，因此不会伪造旧时长或热力图。
- `daily_stats` 为 SQLite view，以当前设备本地时区按 startAt 聚合。改变时区后查询日期可能变化。
- 备份 schema version=1，数据库 schema version=2。恢复为合并数据库、替换设置；仅本地操作，没有远端同步。zip 预览限制 1,000 条目、单条 32MiB、总解压 128MiB，拒绝重复 / 越界路径和无效 JSON；字体在修改数据库前校验。数据库事务与 DataStore 不属于同一跨存储事务，存储故障时可重试同一备份，数据合并幂等。
- 书架索引之外的已移除书籍统计 / 摘录也进入备份；重新导入原文件后，现存摘录凭相同哈希恢复跳转。缓存不是备份内容；外部原书与系统授权不随备份转移。
- 系统强制杀进程可能丢失当前尚未提交的阅读会话。正常暂停 / 退出和 30 秒空闲会持久化。没有为计时启动服务或唤醒锁。

## 自动验证与设备复验

```bash
export JAVA_HOME=/home/box/jdk17 ANDROID_HOME=/home/box/Android
./gradlew assembleDebug test lintDebug
```

37 项测试在 debug / release 各通过一次，含 19 项原有解析 / 定位测试与 18 项新增时序、迁移、备份、存储、设置及性能数据准备测试。主机性能断言是可回归的实现检查，不替代真机 UI 性能报告。本环境当前没有在线 Android 设备；SAF 系统界面、旋转 / 音量键与完整 Compose 绘制仍应按 [validation.md](validation.md) 复验。

设备复验重点：连续读 >10 秒后返回「我的」；读到 30 秒空闲前后；从多个书签跳转；删除 / 失效 / 重导入后的统计和灰态；深浅主题即时切换；备份含 / 不含字体分别恢复；取消预览不修改数据；重复恢复；缓存清理后重开并核对原文件哈希。
