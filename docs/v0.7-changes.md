# Lyric 0.7.0（versionCode 20，分支 feature/0.7）

## 动画
- 书架/画架切换总长 2000ms：0–650 画书 · 650–850 停 · 850–1450 变分镜+小人 · 1450–1650 停 · 1650–2000 淡出、网格升起。保留反向、点按跳过、减弱动画 200ms 交叉淡化。

## 新导入格式
- **PDF**：进书架，保持原版式（PdfRenderer 按屏宽懒渲染 + LRU 缓存），纸色背景、适应宽度、双指缩放、底部页码、按页记进度；首页缩略图作封面。扫描版启发式（全文无 /Font 且含图片对象、非压缩对象流）→ 导入后询问一次是否移到画架。
- **DOCX**：解析 document.xml / styles.xml，Heading 1/2（含中文“标题 1/2”、outlineLvl）分章，无标题时约 3 万字切节；粗体/斜体/居中/图片保留；走现有文本阅读器（主题/字体/划线/搜索）。.doc → 「请另存为 DOCX 后再导入」。
- **MOBI / AZW3**：PalmDB + MOBI/EXTH 头；PalmDOC LZ77 解压；尾随字节处理；组合文件优先取 KF8 部分；图片记录（recindex / kindle:embed）保留；MOBI6 按 mbp:pagebreak 分章、filepos 链接生成目录；KF8 按 HTML 文件分章、目录取章节标题。DRM →「这本书有版权保护，无法导入」。HUFF/CDIC → 明确报错不支持。
- 文件上限 300MB；导入进度新增「取消」；错误信息带失败步骤（如 [MOBI/解压正文]）。
- 书架筛选标签：全部/TXT/EPUB/PDF/DOCX/MOBI/最近；封面不加格式角标。

## 已知缺口
- PDF 目录（outline）、文字选择/搜索、重排：未做（P1）。
- HUFF/CDIC 压缩未支持（提示「暂不支持这种压缩格式」）。
- KF8 只用 NCX 的 pos 定位目录，未用 pos_fid；目录不分层级。
- 扫描版判断为启发式，压缩对象流的 PDF 一律视为文字版。
- 无 DB 迁移（仍 v7）。所有新格式均未在真机验证。
