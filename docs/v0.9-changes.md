# v0.9.0 (versionCode 27)

## 1. Long highlights no longer squeeze the desk
- 今日一句 is clamped to 4 lines with an ellipsis. Text longer than 60 characters gets a 展开/收起 toggle (DeskScreen).
- 今日一句 and 换一句 prefer highlights of 80 characters or fewer, falling back to all highlights (DeskViewModel.preferShort).
- Notes previews collapse blank paragraphs and runs of whitespace (compactPreview) and show at most 2 lines.

## 2. Whole-app jank / dropped-frame audit
See docs/v0.9-perf-audit.md for the full table of findings (area, file:line, problem, fix, impact). Main points:
- Reader: unchanged binds are short-circuited, reader callbacks are installed once, footer/clock/battery state is read in small composables, the curl layer is recorded only in curl mode, curl geometry objects are reused, and per-draw highlight/paint/Random allocations are removed.
- Pagination: the current and adjacent windows are prioritised, known windows skip main-thread callbacks, Typesetter style filtering is done per window, and chapter offsets use a prefix index (O(1)).
- Settings sheet and TOC: option lists are hoisted and TOC progress is computed only for composed rows.
- Shelf: Coil covers use an explicit measured size, no crossfade and revision cache keys. Tab state is kept with SaveableStateProvider.
- Comic/PDF: archives and renderers open and close on IO, PDF rendering respects both axes, cache keys include height, the LRU is capped at 96 MiB, decode/close is synchronised, and strip mode prefetches ±2 pages.
- Desk: note grouping is remembered and the checkpoint is written once per 15-second boundary.
- Startup/IO: directory creation is deferred, settings are decoded on Default, and the excerpt migration is per-book on IO.
- Build: Baseline Profile seed plus profileinstaller; R8 and resource shrinking on the benchmark variant only; Compose stability config and annotations. Strong skipping is confirmed.
- Test: FullScreenCurlTest flakiness came from a harness looper-drain defect and is fixed.

## 3. App name / icon

## Known gaps

- Only the debug build is shipped. R8 is enabled for the benchmark variant only.
