# v0.9.0 (versionCode 27)

## 1. Long highlights no longer squeeze the desk
- 今日一句 is clamped to 4 lines with an ellipsis. Text longer than 60 characters gets a 展开/收起 toggle (DeskScreen).
- 今日一句 and 换一句 prefer highlights of 80 characters or fewer, falling back to all highlights (DeskViewModel.preferShort).
- Notes previews collapse blank paragraphs and runs of whitespace (compactPreview) and show at most 2 lines.

## 2. Whole-app jank / dropped-frame audit
See docs/v0.9-perf-audit.md for the full table of findings (area, file:line, problem, fix, impact). Main points:
- Reader: unchanged binds are short-circuited, reader callbacks are installed once, footer/clock/battery state is read in small composables, the curl layer is recorded only in curl mode, curl geometry objects are reused, and per-draw highlight/paint/Random allocations are removed.
- Pagination: the current and adjacent windows are prioritised, known windows skip main-thread callbacks, Typesetter style filtering is done per window, and chapter offsets use a prefix index (O(1)).
- Settings sheet and TOC: option lists are hoisted and TOC progress is computed only for composed rows.
- Shelf: Coil covers use an explicit measured size, no crossfade and revision cache keys. Tab state is kept with SaveableStateProvider.
- Comic/PDF: archives and renderers open and close on IO, PDF rendering respects both axes, cache keys include height, the LRU is capped at 96 MiB, decode/close is synchronised, and strip mode prefetches ±2 pages.
- Desk: note grouping is remembered and the checkpoint is written once per 15-second boundary.
- Startup/IO: directory creation is deferred, settings are decoded on Default, and the excerpt migration is per-book on IO.
- Build: Baseline Profile seed plus profileinstaller; R8 and resource shrinking on the benchmark variant only; Compose stability config and annotations. Strong skipping is confirmed.
- Test: FullScreenCurlTest flakiness came from a harness looper-drain defect and is fixed.

## 3. App name / icon
- The launcher label is "lyric", and 「抒情诗」 is removed from the UI (manifest and About).
- The new icon (design/v0.9) is ON HOLD at the owner's request. The previous launcher icon is kept.

## Known gaps
- No on-device frame-time measurement. The Baseline Profile is a handwritten seed, not captured on a device.
- Only the debug build is shipped. R8 is enabled for the benchmark variant only.

## White noise on the focus timer page
- 「环境声」 sits under the ring, with capsules 无/雨声/翻书/炉火 (68×36dp, radius 18).
  - Night: unselected #2A2B2F / #A8A296, selected #A3B38A / #16171A.
  - Day: selected Moss #5E6B4E.
- The volume slider is hidden when 无 is selected.
- Playback is AudioTrack streaming of decoded PCM on IO, with sample-exact loop wrapping and a per-sample 300ms gain crossfade.
- Sound plays only while the timer runs. It pauses with the timer (including the auto-pause when you leave the reader) and stops on finish or reset.
- The last sound and volume are saved in the `focus_noise` SharedPreferences, which are read and written on IO.

- **Audio sources/license:** res/raw/noise_{rain,pages,fire}.ogg (~380 KB total, 30 s mono 24 kHz Vorbis loops) are entirely self-generated by `tools/generate_noise.py` (numpy FFT-shaped noise plus circular envelopes, encoded with ffmpeg). No recordings or third-party samples are used. Released as **CC0 1.0** (public domain dedication).
- Code: audio/NoisePlayer.kt, audio/NoiseState.kt. Tests: NoiseStateTest, NoisePersistenceTest.

## PDF built-in outline TOC
- reader/PdfOutline.kt is a bounded, read-only parser covering:
  - /Outlines with /First and /Next and nested levels.
  - /Dest and /A GoTo actions, plus named destinations from the /Names tree and the legacy /Dests dictionary.
  - Mapping from page objects to page indices.

- It skips content and image streams, guards against cycles, and ignores external or script actions.
- The outline is parsed on IO and cached per PdfPageSource. The comic/PDF chapter dialog shows nested entries with page numbers and jumps on tap. If the PDF has no outline or parsing fails, the dialog falls back to a 「第 N 页」 list.
- Tests: PdfOutlineTest, which uses generated fixture PDFs.

  - 裁白边 「去掉扫描页四周的白边或黑边」
- Switch and sheet colours:
  - Night: sheet #2A2B2F, switch on #A3B38A, off #3A3B40, thumb #F4EFE6, dividers #3A3B40.
  - Day: switch on #5E6B4E.

  - On by default in landscape; portrait always shows single pages. Disabled in 条漫 (vertical) mode.

  - In RTL the order within a spread is reversed. There is no gap between the pages, and a 24dp gradient spine shadow (black 8% → transparent, 12dp on each side) covers the seam.

# v0.9.2 (versionCode 29), from Find X9 Pro feedback on 0.9.1

## White noise: softer, ambient
- All three loops are regenerated by `tools/generate_noise.py`. They are 64 s long, mono, 24 kHz, about 610 KB in total, still entirely self-generated and released as **CC0 1.0**.
  - **雨声:** gentle, distant, steady rain. It is a pink/brown noise bed low-passed at about 2.8–3.8 kHz, with very slow periodic amplitude breathing (±10%) and no drops or clicks. Level is about -30 dBFS RMS with peaks at about -20 dBFS.
  - **翻书:** quiet room tone at about -50 dBFS, with sparse, soft, band-limited page rustles. Rustles come at random 8–20 s intervals, each with its own length, colour and secondary ruffle, so there is no repeating pattern. Level is about -38 dBFS RMS with peaks at about -18 dBFS.
  - **炉火:** a soft low rumble with a slow flicker and sparse low-level crackles. Level is about -31.6 dBFS RMS with peaks at about -18 dBFS.
  - A tanh soft ceiling at about -18 dBFS keeps transients inside the bed.
- **Seamless loops:** the noise is FFT-periodic, all LFOs complete whole cycles per loop, and event envelopes sit on a circular timeline. The generator asserts that the step across the wrap is within normal sample-to-sample variation. The player trims codec padding to whole seconds so the wrap stays sample-exact.
- **Player:**
  - Default volume is now 35%, down from 55%.
  - The slider uses a perceptual curve, gain = v³ (35% ≈ -27 dB).
  - Starting from silence fades in over 800 ms. Switching sound still crossfades over 300 ms, and volume drags use a 50 ms ramp, so there is no zipper noise.
  - The decode cap is raised for the longer loops.
- **Volume slider restyled:** a 2dp rounded track, with the active part #A3B38A at night and #5E6B4E by day. The thumb is a 14dp round paper circle. The M3 thumb gap, vertical bar thumb and stop-indicator dot are gone.

## Comic: phone landscape
- **双页 default:** the per-book setting is now tri-state (`comicSpread: Boolean?`, where null means automatic). Automatic turns on spreads in landscape only when the smallest screen width is ≥ 600dp (tablets and foldables). Phones default to single pages in landscape. The user can still switch 双页 on per book; on phones the subtitle reads 「横屏时两页并排（手机默认单页）」.
- **Fill width in landscape:** single pages and spreads fill the screen width, with only a 4dp side margin. When the artwork is taller than the screen it scrolls vertically within the page. Taps still turn pages and toggle the menu, and pinch zoom still works (scroll pauses while zoomed). 裁白边 is taken into account: the trimmed aspect ratio sets the layout height. Landscape pages are decoded bounded by width, so they stay sharp when filling the width.
- **Immersive landscape:** the system bars are hidden (swipe to show transiently), and content extends into the display cutout (short edges). Both are restored when you leave or rotate back to portrait.
- Code: ComicReaderScreen.kt, ComicLayout.kt, reader/PageLayout.kt (`Spreads.enabled`), core/Models.kt.
- Tests: PageLayoutTest (spread default and book override), NoiseStateTest (perceptual curve, 800 ms fade-in), StorageAndSettingsTest (tri-state persistence).

## Known gaps (0.9.2)
- The loudness target is RMS-based (about LUFS for broadband noise), not a measured BS.1770 LUFS. It still needs a listening check on the device.
- In landscape fill-width mode, the next page starts at the top. There is no "continue scrolling into the next page" behaviour.
- Portrait comic system-bar behaviour is unchanged.

# v0.9.5 (versionCode 32)

All six deferred compatibility items (R1–R6) from docs/v0.9-compat-audit.md are fixed. Details, file:line evidence and test names are in the audit doc. UI, animations and features are unchanged.

- **R1 SAF grant cleanup:** removing a book, or a failed import, releases persisted URI grants only when no remaining book or tree still references them. The cleanup runs serially with imports. (UriGrants.kt, LibraryRepository.kt; UriGrantCleanupTest)
- **R2 Large-EPUB memory:** the text EPUB is unpacked by streaming into a private temp dir and resources are read one at a time. The parsed-book memory cache is now byte-budgeted (BookMemoryCache) instead of "2 books". The cache format is unchanged. (EpubParser.kt, LibraryRepository.kt; BookMemoryCacheTest)
- **R3 Pager/bitmap peak:** a shared byte budget now covers comic/PDF bitmaps that pages still hold, scaling decode size down when over budget. CBZ entries are decoded by streaming. When a slide/curl snapshot hits OutOfMemoryError, the turn falls back to a non-animated one. (PageBitmapBudget.kt, PageSnapshot.kt, ComicPages.kt, PdfPages.kt, PageSizing.kt, ReaderCanvas.kt, ReaderScreen.kt; PageMemorySafetyTest)
- **R4 DRM classification:** META-INF/encryption.xml is inspected. Font obfuscation alone is allowed. Encrypted content documents or encrypted ZIP entries fail with 「该书受 DRM 保护，无法打开」. (ArchiveSafety.kt, EpubParser.kt, ImageEpub.kt, ComicParser.kt, BookFormats.kt; ArchiveSafetyTest)
- **R5 Pause timeout:** the pause write barrier is bounded with withTimeoutOrNull, so it can't cause an ANR. Write ordering is preserved. (PauseBarrier.kt, ViewModels.kt, ProgressWriter.kt; PauseBarrierTest)
- **R6 Import hard-cancel:** cooperative cancellation checks run in the EPUB unzip and image-EPUB scans. CancellationException is no longer swallowed. CBZ and image EPUBs have the same 10,000-entry limit as text EPUBs. (ImportProgress.kt, Streams.kt, ArchiveSafety.kt and the parsers; ArchiveSafetyTest)

# v0.9.7.1 (versionCode 35)

新瑞在 Find X9 Pro 上觉得 0.9.7 打开大书仍卡。本版做按需 EPUB 解析，并同时交付 Debug 与优化包。0.9.7 骨架视觉与 300/300/150ms 防闪不变。完整热点、主机前后对比与风险见 docs/v0.9.7-load-jank.md 与 README。

## 按需 EPUB 解析
- 缓存未命中时，先解析 TOC/spine + 当前章及前后各一章，即可进入阅读。其余章节在后台逐章解析并写入分章缓存。
- 第二次打开走缓存，不再整本重解析。旧 parsed-v1 全书 JSON 仍可读；新导入使用分章缓存。
- 目录、搜索、书签、划线或翻页进入尚未解析的章时，先解析该章。若超过 300ms，使用既有骨架与防闪规则（无转圈、进度条或额外文字）。目录里未解析章外观与已解析章相同，不发灰。
- 后台解析不占用主线程、不持 parseLock、不刷新整本 StateFlow，避免翻页、滚动和返回书架时卡顿。
- 全书字符长度在公布百分比之前先稳定；冷开长度未齐时暂时不显示百分比、不可拖全书进度，避免位置跳动。书签/划线/搜索使用 canonical 文本偏移，填充后不漂移。
- 主要文件：EpubParser.kt、DeferredChapters.kt、EpubChapterCache.kt、LibraryRepository.kt、ViewModels.kt、ReaderScreen.kt、TextSelection.kt、AnnotationPanels.kt。测试：IncrementalEpubTest。
