# Lyric 0.8.0（versionCode 22，分支 feature/0.8）

## 案头页
- 底栏改为「书架/画架 · 案头 · 我的」。本地导入不再占底栏，仍从右上角「+」进入。
- 案头图标：摊开书线稿（`Icons.Outlined.MenuBook`），线宽同书架图标。
- **今日小结**：标题下 13sp 灰字一行「今天读了 X 分钟 · Y 页 · Z 条笔记」。无卡片、无排行、无打卡。页数按会话字数估算（文字约 /400，漫画按页增量）。
- **今日一句**：卡片 `#EAE3D6`、圆角 20dp；宋体 18sp；左侧 2dp 朱红竖线；「换一句 ↻」青苔色。点句子跳回原文对应划线位置。无划线时安静空态。
- **专注阅读**：25 / 45 分段（选中青苔色）；默认上次读的文字书，可「更换」；「开始」墨色 `#2B2A27`。
- **计时页**：背景 `#16171A`；**默认隐藏状态栏**（与是否勿扰无关）；240dp 圆环，进度 3dp `#E08A6E` 圆头；时间宋体 52sp 细体；左「暂停」描边、右「继续阅读」填充；结束仅轻震一次并写入时长，不弹窗。杀进程后可恢复未结束的专注会话。
- **屏蔽通知**：默认关；仅用户打开时才跳转系统页申请勿扰权限；开关旁小字「需要勿扰权限」。开启后计时页顶部显示「勿扰中 · 书名」。
- **笔记**：案头预览最近 2 条；「全部」进入完整列表（沿用 0.5 划线样式 + 按书/按时间 + 搜索），点一条跳回原文。

## 数据库
- Room v8：新增 `focus_sessions`；`MIGRATION_7_8`。专注结束后写入 `reading_sessions`（chars=0）以计入今日分钟。

## 不做（留给 0.8.x / 0.9）
- 笔记导出 Markdown / 图片卡片、白噪音。

## 已知缺口
- 今日「页」为估算值；专注期间翻页产生的阅读会话与专注整段时长可能部分重叠。
- 未在真机验证勿扰权限引导、计时杀进程恢复、轻震。

# Lyric 0.8.1（versionCode 23）
## 返回逻辑
- 计时页、完整笔记列表改为独立导航页（`focus` / `notes`），系统返回键和预测性返回手势都回到案头首页；计时页全屏，不再显示底栏。
- 从计时页返回后专注继续计时，案头专注卡显示「专注中 mm:ss」行，点一下回到计时页；计时结束自动关闭计时页。
- 计时页「继续阅读」用阅读页替换计时页，从阅读页返回直接回到案头（0.8.0 会卡回计时页且返回无效）。
- DeskViewModel 提升到 Activity 作用域，跨页面共享专注会话。开启 `enableOnBackInvokedCallback`。
## 滑动掉帧
- 案头从 Column+verticalScroll 改为带 key 的 LazyColumn。
- 计时器每 250ms 的状态只在「专注中」小组件里收集，案头其余部分不再随计时重组（0.8.0 整页每秒重组 4 次）。
- 去掉案头重复叠加的纸纹绘制（外层已有）。
## 已知缺口
- 离开计时页时会恢复系统通知（勿扰只在计时页可见时生效）。
- 仍是 debug 包，滑动流畅度比正式包略差；未做 baseline profile。

# Lyric 0.8.2（versionCode 24）
- **重置专注**：计时页底部加「重置」；案头「专注中/已暂停」行右侧也有「重置」。重置即结束当前会话回到空闲；已读满 1 分钟的部分计入今日阅读时长，不足 1 分钟不记。无确认弹窗。
- **45 分钟点不了**：0.8.1 在有会话（含暂停）时 25/45 被静默锁住。现在有会话时专注卡只显示会话行（回到计时 / 重置），不显示时长分段和「开始」；空闲时分段和「开始」都可点。
- **删除「屏蔽通知」**：去掉开关、勿扰权限申请、「勿扰中」字样（清单里本来没有勿扰权限声明）。计时页仍隐藏状态栏。
- 专注卡和「更换」列表显示书的真实封面（与书架同源，Coil 按缩略图尺寸加载），无封面才用占位。
- 书名行：章节名是 Cover/封面/扉页/目录或空时只显示书名。

# Lyric 0.8.3（versionCode 25）
- **目录页倒计时**：专注会话对应的书在阅读页打开时，目录抽屉书名下显示「专注中 · 剩余 mm:ss」（朱红；暂停时灰色「已暂停」）。只有这一行随计时刷新。
- **离开阅读页自动暂停**：专注计时只在该书的阅读页可见时走；返回案头、切到后台或锁屏即暂停，回到阅读页自动继续（计时页本身仍计时）。
- **案头会话行**：显示「已暂停/专注中 mm:ss · 书名」，主按钮「继续阅读」直接回到该书上次位置并继续计时；次要「回到计时」「重置」。
- **排版面板掉帧**：纸纹改为每个尺寸只栅格化一次的位图（原来每帧画最多 1.8 万个点，书页、案头、面板都受影响）；排版面板内容不再叠加纸纹（原来覆盖整段滚动内容，面板弹出动画每帧重画）。
## 已知缺口
- 未用 Perfetto/GPU 渲染分析在真机上测，掉帧原因是看代码判断的；若仍卡，下一步查仿真翻页的页面层录制。
- 杀进程后恢复的未暂停会话，会在回到阅读页前先走一段。
