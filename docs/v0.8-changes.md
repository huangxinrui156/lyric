# Lyric 0.8.0（versionCode 22，分支 feature/0.8）

## 案头页
- 底栏改为「书架/画架 · 案头 · 我的」。本地导入不再占底栏，仍从右上角「+」进入。
- 案头图标：摊开书线稿（`Icons.Outlined.MenuBook`），线宽同书架图标。
- **今日小结**：标题下 13sp 灰字一行「今天读了 X 分钟 · Y 页 · Z 条笔记」。无卡片、无排行、无打卡。页数按会话字数估算（文字约 /400，漫画按页增量）。
- **今日一句**：卡片 `#EAE3D6`、圆角 20dp；宋体 18sp；左侧 2dp 朱红竖线；「换一句 ↻」青苔色。点句子跳回原文对应划线位置。无划线时安静空态。
- **专注阅读**：25 / 45 分段（选中青苔色）；默认上次读的文字书，可「更换」；「开始」墨色 `#2B2A27`。
- **计时页**：背景 `#16171A`；**默认隐藏状态栏**（与是否勿扰无关）；240dp 圆环，进度 3dp `#E08A6E` 圆头；时间宋体 52sp 细体；左「暂停」描边、右「继续阅读」填充；结束仅轻震一次并写入时长，不弹窗。杀进程后可恢复未结束的专注会话。
- **屏蔽通知**：默认关；仅用户打开时才跳转系统页申请勿扰权限；开关旁小字「需要勿扰权限」。开启后计时页顶部显示「勿扰中 · 书名」。
- **笔记**：案头预览最近 2 条；「全部」进入完整列表（沿用 0.5 划线样式 + 按书/按时间 + 搜索），点一条跳回原文。

## 数据库
- Room v8：新增 `focus_sessions`；`MIGRATION_7_8`。专注结束后写入 `reading_sessions`（chars=0）以计入今日分钟。
