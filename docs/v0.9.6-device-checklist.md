# Lyric 0.9.3–0.9.6 · OPPO Find X9 Pro（ColorOS）真机验收

## 必须先通过的三项

- [ ] **大 EPUB 与长条漫不崩溃。** 使用实际大 EPUB（文字、多章、插图，处于现有导入限制内）完成导入、打开、目录跳转、连续翻页与重新打开；使用长条漫 CBZ/图片 EPUB 连续滚动至少 5 分钟，快速往返、横竖屏切换、回书架再开。无闪退、ANR、持续白屏或回收位图绘制错误；记录文件大小、章节/图片数、耗时和内存峰值。超限样本应友好拒绝，不能崩溃。
- [ ] **强制停止后阅读进度保留。** 分别在文字 EPUB、漫画、PDF 中读到可辨认的位置，记录章节、首句/物理页码、百分比。先测 Home/锁屏后强停，再测前台位置已保存后直接强停（可用 `adb shell am force-stop com.lyric.reader`），从桌面重开仍回到同一内容；每类重复 3 次，书签、划线和累计阅读记录不被清空。另测翻页后立即杀进程并记录最后已落盘位置，不把不存在的强杀回调当成保存保证。
- [ ] **ColorOS 主题图标显示正确。** 在系统桌面启用该 ROM 提供的主题/随壁纸配色选项，换两组壁纸颜色并切换明暗模式；图标保留叶片、笔划和圆点，单色随主题变色，无空白、矩形色块或裁断。记录系统桌面版本和实际选项名称；若 ROM 不提供该选项，标记“无法执行”，不能填通过。

## 漫画双页与翻页

- [ ] Find X9 Pro 以实际 `smallestScreenWidthDp` 判断：手机双页提示为「横屏时可并排显示两页」；手机默认不自动打开双页，本书手选状态重开仍保留。若借助大屏/分屏配置复核 sw≥600dp，提示与默认行为按现有规则变化。
- [ ] 横屏开启双页：第 1 页封面始终独页。5 页样本应为 `[0] [1,2] [3,4]`，6 页样本最后单页；开启偏移后封面仍独页、紧接的第一页也独页，再开始配对。

- [ ] 系统动画倍率 1× 时，点按左右翻页区、音量键翻页的 pager 过渡为 200ms；左右阅读方向、反转音量键、首尾页边界均正确。滑动、双击缩放、裁边等其他动画保持既有表现。
- [ ] 横竖屏切换、开关双页/偏移后仍锚定同一物理页；返回书架再进入不跳到不相关章节。横屏状态栏收起、返回后恢复，刘海两侧控件可点击。

## 白噪音

- [ ] 专注计时页的「无 / 雨声 / 翻书 / 炉火」均能选择；未开始计时、暂停、结束时不继续发声。
- [ ] 默认音量 35%，开始约 800ms 淡入、换声约 300ms 交叉淡化；拖动音量无爆音，音量零完全静音。耳机与扬声器分别听验。
- [ ] 各声音连续播放至少 3 分钟，跨循环边界无明显停顿/点击声；人耳记录是否过响，不用主机 RMS 推定设备听感。
- [ ] 选择与音量在退出、强停、重开后恢复；不自动开始计时/播放。
- [ ] 来电/其他音频应用抢焦点、耳机拔出时按既有策略静音，计时不被噪音错误暂停；短暂焦点恢复后恢复，永久失焦/拔出后通过暂停再继续恢复。锁屏与省电场景记录实际行为。

## 功能设计 C：失效文件、导入汇总与 DRM

### C(a) 文件访问失效与恢复

- [ ] 导入一本文字 EPUB，读到中部并记下位置/书签；在外部提供者撤销授权，或移走/清理其源文件，回书架触发来源检查。网格与列表均沿用「文件失效」暗色遮罩，不出现正常可读的假象。
- [ ] 点击失效项，在书架显示 **「文件访问已失效，重新选择即可恢复进度」**；来源恰在打开时才失效也显示同样文案，不裸露异常类名。
- [ ] 通过现有「本地导入 → 选择文件」重新选择**相同字节内容**的原书（可以改位置/名称）；书架只有一条，失效样式清除，章节/字符位置/漫画页、百分比、书签、划线与阅读历史保留。不把内容不同的新书视为同一书。
- [ ] 私有源副本仍存在时，外部源丢失不误标失效；私有副本和外部源都不可用时才显示恢复提示。仅清理可重建的解析缓存不丢进度。

### C(b) 超时、取消也显示汇总

- [ ] 普通完成、包含失败、超时与主动取消后都能看到 **「导入 n · 跳过 n · 失败 n」**；文件选择入口和文件夹入口都测。完成项不能被取消后的新状态清零。
- [ ] 混合批次示例：第 1 本导入成功、第 2 本重复，第 3 本进行中取消、第 4 本尚未开始，结果为 **「导入 1 · 跳过 2 · 失败 1」**。跳过包含重复和未开始项；当前中止项记失败并显示「导入已取消」，未开始项不真正读取。
- [ ] 文件夹扫描阶段取消时仍有零计数汇总及取消原因，不凭空算出一本失败书。目录源信息仍保留。
- [ ] 超时当前文件计失败，已导入/重复计数保留，后续文件按既有流程继续。原因如 **「文件太大或结构异常，超时已停止」**，附文件名；不直接展示 `TimeoutException` 或 `[解析书籍]`。
- [ ] 结果弹窗内汇总与逐项原因可见、可滚动、可关闭；关闭后可以发起新导入。失败文件没有新的书架条目或残余导入临时文件。

### C(c) DRM 文案与清理

- [ ] 分别导入正文加密 EPUB、图片 EPUB、密码 ZIP/CBZ、DRM MOBI/AZW3，均使用 **「这本书有版权保护，无法导入」**，不再显示「该书受 DRM 保护，无法打开」。
- [ ] DRM 文件计失败，已有书籍与其进度不受影响；失败前后比对书架数量，再强停重开，确认没有半成品书、空白封面条目或误报成功。
- [ ] 可调试构建下核对该文件未留下 `sources-v1` 源副本、`parsed-v1` 解析缓存、封面或 `import-*` 临时文件；仅字体混淆的 EPUB 不误判 DRM。
